# Brainstorming & prototyping — Bensaid

The **Bensaid** design idea: a platform with crate handling using a **crate switcher / blocker** (free rotation, servo-driven) and **suction cups** on rails.

## Contents
- `bensaid` assembly, base, middle separation wall and crate compartment walls
- `crate SWITCHER`, `crate blocker`, `switcher free rotation` — crate handling parts
- `suction holder`, `suction cup rail support`, `suction cup holder rotation axe` — suction-cup system
- `guiding rail`, `servo support`, `slope` — rails and supports
- `PROTOTYPE/` — prototype files
- `piece util/` — reusable parts
